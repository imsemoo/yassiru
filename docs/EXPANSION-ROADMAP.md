# خطة توسع منصة يسّرو — من منصة تيسير زواج إلى منظومة أسرية متكاملة

> هذه الخطة للتوسع بعد الإطلاق — لا يُنفَّذ منها شيء قبل استقرار MVP وتحقيق أول 1000 مستخدم.

---

## الرؤية الكبرى

يسّرو حالياً تحل مشكلة **الزواج الأول**. لكن الرحلة الأسرية أكبر من كده:

```
الزواج الأول ← الحياة الزوجية ← الأبناء ← الزواج الثاني (لو حصل طلاق/ترمل)
     ↑                  ↑              ↑              ↑
  يسّرو الآن      توسع قريب       توسع متوسط      توسع بعيد
```

---

## المرحلة 1: تعميق المنتج الحالي (شهر 1-3 بعد الإطلاق)

### 1.1 نظام تقييم المعرّفين
**المشكلة:** المستخدم مش عارف مين أحسن معرّف.
**الحل:**
- بعد كل توصية ناجحة (تحولت لخطبة/زواج)، العائلتان يقيّموا المعرّف
- تقييم 5 نجوم + تعليق مختصر
- المعرّفين الأعلى تقييماً يظهروا أول في البحث
- badge "معرّف متميز" لمن وصل 4.5+ نجمة مع 10+ توصيات ناجحة

### 1.2 نظام دردشة محدود (معرّف ↔ عائلات)
**المشكلة:** التواصل حالياً بالهاتف فقط — مفيش توثيق.
**الحل:**
- دردشة نصية داخل المنصة بين المعرّف وولي الأمر فقط
- **لا دردشة بين الرجل والمرأة** — ده خط أحمر
- كل الرسائل محفوظة كسجل لو حصل نزاع
- إشعارات فورية عند رسالة جديدة

### 1.3 إشعارات واتساب
**المشكلة:** الإيميل مش بيتقرأ — الفئة المستهدفة بتستخدم واتساب.
**الحل:**
- ربط WhatsApp Business API
- إشعارات: تذكير مساهمة، تأكيد دفع، توصية جديدة، تذكير جلسة
- الـ API جاهز — محتاج بس integration مع Twilio أو Meta Business

### 1.4 تطبيق موبايل (PWA أولاً ← Flutter لاحقاً)
**المشكلة:** 70%+ من المستخدمين على الموبايل.
**الحل:**
- PWA موجود بالفعل (manifest + service worker)
- الخطوة القادمة: Push Notifications عبر Firebase
- بعدها: Flutter app يستخدم نفس الـ API بدون أي تغيير في الـ backend

## المرحلة 2: ميزات جديدة تزيد القيمة (شهر 3-6)

### 2.1 الزواج مرة أخرى (المطلقين والأرامل)
**المشكلة:** 40% من حالات الطلاق في السنتين الأولى. المطلقون والأرامل محتاجين دعم خاص.
**الحل:**
- **مسار تأهيلي خاص** — دروس مختلفة عن الزواج الأول:
  - التعامل مع تجربة الزواج السابق
  - كيف تبدأ من جديد
  - حقوق الأبناء من الزواج الأول
  - التعامل مع الزوج/الزوجة السابقة
- **فلتر في نظام التوفيق** — المعرّف يحدد: "مطلق/أرمل يبحث عن مطلقة/أرملة"
- **مسار مالي مختلف** — ميزانية الزواج الثاني مختلفة (مفيش تجهيز شقة مثلاً)
- **حاسبة مخصصة** — تكاليف الزواج الثاني vs الأول
- **صندوق تيسير مخصص** — حلقات للمطلقين/الأرامل (مبالغ أقل، دورات أقصر)

### 2.2 نظام الشراكات والخصومات
**المشكلة:** حتى مع العرس الجماعي، فيه تكاليف تانية (أثاث، أجهزة، شقة).
**الحل:**
- **دليل موردين معتمدين** — أثاث، أجهزة، مصورين، قاعات، شقق
- **خصومات حصرية** لحاملي شهادة يسّرو
- **نظام كوبونات** — المورد يعمل كوبون خصم، يسّرو تاخد عمولة صغيرة
- **مقارنة أسعار** — المستخدم يقارن بين الموردين
- **تقييمات** من أزواج سابقين

### 2.3 المحفظة الرقمية
**المشكلة:** فوري ممتاز بس المستخدم محتاج يشوف رصيده ومعاملاته في مكان واحد.
**الحل:**
- محفظة داخلية تعرض: المدفوع، المتبقي، المسترد
- سجل معاملات كامل بالتواريخ
- إيصالات PDF لكل عملية
- ربط مع الصندوق: "دورك بعد 3 أشهر — المتبقي: 12,000 ج.م"

### 2.4 نظام الإحالة (Referral)
**المشكلة:** النمو العضوي بطيء.
**الحل:**
- كل مستخدم عنده كود إحالة فريد
- لما حد يسجل بالكود → المحيل ياخد نقاط
- النقاط تتحول لـ: خصم على رسوم الصندوق، أو أولوية في قائمة الانتظار
- لوحة "أكثر المحيلين" — gamification خفيف

## المرحلة 3: توسع جغرافي (شهر 6-12)

### 3.1 الخليج (السعودية + الإمارات + الكويت)
**لماذا الخليج؟**
- أعلى تكلفة زواج في العالم (متوسط 200,000-500,000 ريال)
- قدرة شرائية عالية = إيرادات أعلى
- مشكلة العنوسة موجودة بقوة

**التغييرات المطلوبة:**
- إضافة عملات: SAR, AED, KWD
- بوابة دفع: Stripe (البنية جاهزة — محتاج بس Provider جديد)
- مدن جديدة في الـ seeder
- تكاليف زواج مختلفة تماماً
- شراكات مع موردين محليين
- **أعراس جماعية** مفهومها مختلف في الخليج — محتاج تكييف

### 3.2 شمال أفريقيا (المغرب + تونس + الجزائر)
- عملات: MAD, TND, DZD
- لغة: العربية + الفرنسية (i18n)
- تكاليف مختلفة
- ثقافة زواج مختلفة عن مصر

### 3.3 تركيا + جنوب شرق آسيا
- إندونيسيا (أكبر دولة إسلامية — 270 مليون)
- ماليزيا
- تركيا
- **ترجمة كاملة** — vue-i18n جاهز للإضافة بدون إعادة بناء

## المرحلة 4: منظومة أسرية متكاملة (سنة 1-2)

### 4.1 أكاديمية يسّرو (بعد الزواج)
**المشكلة:** الدورة التأهيلية تنتهي عند الشهادة — بس الحياة الزوجية بتحتاج تعلم مستمر.
**الحل:**
- **كورسات مدفوعة** ($5-15 لكل كورس):
  - "السنة الأولى — دليل البقاء" (6 دروس)
  - "فن التواصل الزوجي" (4 دروس)
  - "إدارة المال كزوجين" (4 دروس)
  - "التربية الواعية" (8 دروس) — لما يجي أطفال
  - "التعامل مع أهل الزوج/الزوجة" (3 دروس)
- **شهادات إضافية** لكل كورس
- **منتدى نقاشي** خاص بكل كورس
- **بث مباشر** شهري مع مستشار أسري

### 4.2 مجتمع الأزواج
**المشكلة:** الأزواج الجدد بيحسوا بالعزلة — مفيش مجتمع داعم.
**الحل:**
- **مجموعات أزواج** حسب المنطقة الجغرافية
- **منتور** — زوج/زوجة خبير (5+ سنوات) يوجه زوج جديد
- **لقاءات شهرية** أونلاين + أوفلاين
- **قصص نجاح** — أزواج يسّرو يشاركوا تجربتهم
- **تحديات أسبوعية** — "تحدي التقدير" أو "تحدي التواصل" — gamification

### 4.3 صندوق الطوارئ الأسري
**المشكلة:** أزمات مالية مفاجئة بتهدد الاستقرار الأسري.
**الحل:**
- صندوق تعاوني (نفس مفهوم الجمعية) بس للأسر
- كل أسرة تساهم بمبلغ صغير شهرياً (50-200 ج.م)
- عند طوارئ (مرض، فقد وظيفة) — الأسرة تحصل على دعم مالي
- بدون فوائد — تكافل اجتماعي حقيقي

### 4.4 استشارات متقدمة
**المشكلة:** الاستشارات الحالية بسيطة (حجز جلسة + إلغاء).
**الحل:**
- **فيديو كول** مباشر مع المستشار (Zoom/Jitsi integration)
- **تخصصات**: مستشار شرعي، نفسي، مالي، تربوي
- **باقات** شهرية: جلسة واحدة ($10) / 4 جلسات ($30) / غير محدود ($50)
- **جلسات جماعية** — أرخص ومفيدة لمواضيع عامة
- **خط طوارئ 24/7** — واتساب مباشر مع مستشار متاح

## المرحلة 5: ابتكارات (سنة 2+)

### 5.1 AI Matching — توفيق بالذكاء الاصطناعي
**الفكرة:** الخوارزمية الحالية بسيطة (city + age + religiosity). ممكن نخليها أذكى بكتير.
**التطوير:**
- تحليل أنماط الزيجات الناجحة (اللي فضلت سنة+ بدون مشاكل)
- عوامل جديدة: الشخصية (MBTI-like), القيم, أسلوب الحياة, التوقعات
- اختبار شخصية قصير (20 سؤال) عند التسجيل
- الخوارزمية تتعلم من النتائج وتتحسن مع الوقت
- **خط أحمر:** الاقتراحات تروح للمعرّف مش للمستخدم مباشرة

### 5.2 B2B — يسّرو للمؤسسات
**الفكرة:** مؤسسات خيرية وجمعيات بتنظم أعراس جماعية بشكل يدوي.
**الحل:**
- **لوحة تحكم مؤسسية** — المؤسسة تدير أعراسها عبر يسّرو
- **White-label** — المؤسسة تستخدم يسّرو بشعارها
- **تقارير** — إحصائيات الزيجات، التكاليف، الأثر الاجتماعي
- **اشتراك شهري** $50-200 حسب حجم المؤسسة
- **أمثلة:** جمعيات تيسير الزواج في السعودية، مؤسسات خيرية في مصر

### 5.3 يسّرو Pay — محفظة إسلامية
**الفكرة الكبيرة:** بعد ما نبني ثقة مع آلاف الأسر، نقدر نوسع الخدمات المالية.
**الحل:**
- محفظة رقمية للادخار الأسري
- تحويلات بين أعضاء الأسرة
- ربط مع بنوك إسلامية (تمويل بدون ربا)
- **ميكروتمويل** — قروض حسنة صغيرة لتأثيث المنزل
- شراكة مع بنوك مثل: فيصل الإسلامي، البركة

### 5.4 يسّرو Education — منصة تعليمية أسرية
**الفكرة:** توسيع الأكاديمية لتشمل كل الأسرة.
- كورسات للآباء: التربية الإيجابية، التعامل مع المراهقين
- كورسات للأمهات: الصحة النفسية، إدارة المنزل والعمل
- كورسات للأطفال: القيم الإسلامية بطريقة تفاعلية
- **اشتراك عائلي** $5/شهر
