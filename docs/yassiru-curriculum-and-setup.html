🕌 المسار الأول: التأهيل الشرعي (4 دروس — 3 ساعات)

المصادر: كتب الفقه المعتمدة عند أهل السنة + فتاوى اللجنة الدائمة + كتاب "عشرة النساء" لابن الجوزي

الدرس 1 — 45 دقيقة — فيديو
الزواج في الإسلام: غايته وأحكامه
  • الزواج سنة النبي ﷺ وميثاق غليظ — ليس عقداً تجارياً
  • الحِكم من تشريع الزواج: السكن والمودة والرحمة
  • أركان عقد الزواج وشروط صحته
  • صفات الزوج الصالح وصفات الزوجة الصالحة — من السنة
  • الاستخارة والاستشارة قبل القرار
الدرس 2 — 45 دقيقة — فيديو
حقوق الزوجين: ما لك وما عليك
  • حقوق الزوجة: النفقة، المسكن، المعاشرة بالمعروف، العدل
  • حقوق الزوج: الطاعة بالمعروف، حفظ الغيب، القرار المشترك
  • الحقوق المشتركة: المودة، الاحترام، الصدق، التعاون
  • الفرق بين القوامة والتسلط — فهم صحيح
  • حق كل طرف في الخصوصية والمساحة الشخصية
الدرس 3 — 45 دقيقة — فيديو
آداب الخلاف وحل النزاعات شرعياً
  • الخلاف طبيعي — النبي ﷺ اختلف مع زوجاته
  • آداب الغضب: لا ضرب، لا سب، لا تهديد بالطلاق
  • خطوات حل الخلاف: النصيحة → الهجر في المضجع → التحكيم
  • دور الأهل: متى يتدخلون ومتى لا
  • الطلاق: آخر الحلول لا أولها — أحكامه وآدابه
الدرس 4 — 45 دقيقة — فيديو
العلاقة الزوجية الحميمة — الآداب الشرعية
  • مكانة العلاقة الحميمة في الإسلام — عبادة وصدقة
  • آداب الجماع: الدعاء، الملاطفة، مراعاة الطرفين
  • المحرمات: الإتيان في الدبر، الجماع في الحيض
  • حق كلا الزوجين في الاستمتاع — بدون حرج
  • التوقعات الواقعية vs ما يُروَّج له
ملاحظة: هذا الدرس يُعرض بلغة علمية محترمة — يُراجع بالكامل من الهيئة الشرعية قبل النشر. يُفصل بين نسخة الرجال ونسخة النساء إذا لزم الأمر.

🧠 المسار الثاني: التأهيل النفسي (4 دروس — 3 ساعات)

الدرس 1 — 45 دقيقة
مهارات التواصل الفعّال بين الزوجين
  • الفرق بين الاستماع والإنصات — الإنصات الفعّال
  • لغة "أنا أشعر" بدل "أنت دائماً" — التواصل بدون اتهام
  • قراءة لغة الجسد — ماذا يقول شريكك بدون كلام
  • 5 لغات للحب: كلمات التقدير، الأفعال، الهدايا، الوقت، اللمس
  • تمرين عملي: محادثة نموذجية (قبل وبعد)
الدرس 2 — 45 دقيقة
إدارة التوقعات — الواقع vs الخيال
  • لماذا نتوقع الكمال؟ تأثير الدراما والسوشيال ميديا
  • قائمة التوقعات الواقعية: ماذا تتوقع فعلاً من الزواج
  • صدمة الواقع: الأشهر الثلاثة الأولى — طبيعية وليست فشلاً
  • الفرق بين "شريك مثالي" و"شريك مناسب"
  • تمرين: اكتب توقعاتك وناقشها مع نفسك بصراحة
الدرس 3 — 45 دقيقة
الذكاء العاطفي في الحياة الزوجية
  • ما هو الذكاء العاطفي ولماذا هو أهم من الذكاء العقلي في الزواج
  • الوعي بمشاعرك: كيف تعرف إنك غاضب/حزين/محبط قبل ما تتصرف
  • التعاطف: كيف تشعر بما يشعر به شريكك
  • إدارة الغضب: تقنيات عملية (التوقف، التنفس، التأجيل)
  • كيف تعتذر بصدق — ولماذا الاعتذار ليس ضعفاً
الدرس 4 — 45 دقيقة
التعامل مع الضغوط والأزمات
  • أنواع الضغوط: مالية، عائلية، وظيفية، صحية
  • كيف الضغوط تؤثر على العلاقة — ولماذا لا نحمّل الشريك
  • استراتيجيات المواجهة كفريق (نحن vs المشكلة، مش أنا vs أنت)
  • متى نطلب مساعدة متخصصة — وليس عيباً
  • بناء "صندوق أمان عاطفي" — عادات يومية تقوّي العلاقة

💰 المسار الثالث: التأهيل المالي (3 دروس — 2.5 ساعة)

الدرس 1 — 50 دقيقة
بناء ميزانية الأسرة من الصفر
  • الفرق بين الدخل والمصروف — ولماذا معظم الأسر لا تعرف أين يذهب المال
  • قاعدة 50/30/20: الاحتياجات / الرغبات / الادخار
  • أدوات مجانية لتتبع المصاريف (تطبيقات + Excel)
  • تمرين عملي: اعمل ميزانية شهرية لأسرة براتب X
  • من المسؤول عن الميزانية؟ الجواب: الاثنان معاً
الدرس 2 — 50 دقيقة
تأسيس البيت بأقل تكلفة — بدون ديون
  • ترتيب الأولويات: ما تحتاجه فعلاً vs ما المجتمع يضغط عليك لشرائه
  • البداية بالأساسيات والتدريج — لا تشتري كل شيء دفعة واحدة
  • المستعمل vs الجديد — أين توفر ومتى تستثمر
  • خطر الديون والتقسيط في بداية الزواج
  • صندوق الطوارئ: لماذا تحتاجه من اليوم الأول
الدرس 3 — 50 دقيقة
التخطيط المالي طويل المدى للأسرة
  • أهداف مالية: 6 أشهر / سنة / 5 سنوات
  • الادخار للأطفال والتعليم — ابدأ من اليوم
  • التأمين الصحي والاجتماعي — هل تحتاجه؟
  • مصادر دخل إضافية حلال — أفكار عملية
  • كيف تتحدث مع شريكك عن المال بدون خلاف

🏠 المسار الرابع: التأهيل العملي (3 دروس — 2 ساعة)

الدرس 1 — 40 دقيقة
إدارة البيت — مهارات أساسية للطرفين
  • تقسيم المهام المنزلية — مش مسؤولية طرف واحد
  • أساسيات الطبخ للمبتدئين — 5 وجبات سهلة
  • تنظيم المنزل بأقل مجهود — نظام بسيط ومستدام
  • إدارة الوقت: عمل + بيت + علاقة — كيف توازن
الدرس 2 — 40 دقيقة
التعامل مع الأهل — من الطرفين
  • أهلك بعد الزواج: علاقة تتطور لكن لا تنقطع
  • أهل الزوج/الزوجة: كيف تبني علاقة صحية بدون تدخل
  • حدود صحية: كيف تقول "لا" بأدب
  • الأم vs الزوجة / الأب vs الزوج — خلاف كلاسيكي وحله
  • الزيارات: كم مرة؟ متى؟ قواعد واقعية
الدرس 3 — 40 دقيقة
السنة الأولى — دليل البقاء
  • أول 3 شهور: فترة تكيّف طبيعية — لا تحكم بسرعة
  • اكتشاف عادات الشريك: بعضها سيزعجك — وده طبيعي
  • بناء تقاليد خاصة بكم: عشاء أسبوعي، نزهة شهرية
  • متى وكيف تخطط للإنجاب — قرار مشترك
  • علامات تحتاج فيها مساعدة متخصصة — لا تتأخر

⚡ سكريبت إعداد المشروع — انسخه وشغّله

setup.sh — شغّل الأوامر دي بالترتيب
# ═══ 1. إنشاء مشروع Laravel ═══
composer create-project laravel/laravel yassiru
cd yassiru

# ═══ 2. تثبيت الحزم المطلوبة ═══
composer require laravel/sanctum
composer require spatie/laravel-permission
composer require spatie/laravel-medialibrary
composer require stripe/stripe-php
composer require laravel/horizon

# ═══ 3. إعداد Vue.js + Bootstrap ═══
npm install vue@3 vue-router@4 pinia axios
npm install bootstrap@5.3.3 @popperjs/core
npm install sass vee-validate yup
npm install @vitejs/plugin-vue

# ═══ 4. إعداد قاعدة البيانات ═══
# عدّل ملف .env:
# DB_DATABASE=yassiru
# DB_USERNAME=root
# DB_PASSWORD=your_password
# CACHE_DRIVER=redis
# QUEUE_CONNECTION=redis
# SESSION_DRIVER=redis

php artisan migrate
php artisan db:seed

# ═══ 5. نشر ملفات الحزم ═══
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"
php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider"
php artisan horizon:install

# ═══ 6. إنشاء المفاتيح ═══
php artisan key:generate

# ═══ 7. تشغيل المشروع ═══
php artisan serve &
npm run dev

📦 Seeder: Roles & Permissions

database/seeders/RoleSeeder.php
use Spatie\Permission\Models\Role;
use Spatie\Permission\Models\Permission;

// Roles
Role::create(['name' => 'admin']);
Role::create(['name' => 'recommender']);
Role::create(['name' => 'user']);

// Permissions
$permissions = [
  'manage-users', 'manage-recommenders', 'manage-circles', 'manage-weddings',
  'manage-courses', 'manage-reports', 'view-admin-dashboard',
  'add-candidates', 'make-recommendations', 'view-recommender-dashboard',
  'enroll-courses', 'join-circles', 'register-weddings', 'submit-reports',
];

foreach ($permissions as $p) {
  Permission::create(['name' => $p]);
}

Role::findByName('admin')->givePermissionTo(Permission::all());
Role::findByName('recommender')->givePermissionTo(['add-candidates','make-recommendations','view-recommender-dashboard','enroll-courses','join-circles']);
Role::findByName('user')->givePermissionTo(['enroll-courses','join-circles','register-weddings','submit-reports']);
