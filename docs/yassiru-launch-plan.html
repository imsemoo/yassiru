📋 فتح الحسابات وتجهيز DNS

1

اشتري الـ Domain

namecheap.com → ابحث عن yassiru.com → اشتري → فعّل Privacy Protection

2

أنشئ SSH Key

على جهازك افتح Terminal:

ssh-keygen -t ed25519 -C "en.developer2@gmail.com"
3

أنشئ سيرفر Hetzner

hetzner.com/cloud → Cloud Server → CX22 → Ubuntu 24.04 → Falkenstein → ارفع SSH Key

4

وجّه DNS

في إعدادات Domain:

A @ → [IP السيرفر]
A www → [IP السيرفر]
5

قدّم على حساب فوري

developer.fawry.io → Merchant Account → ارفع الهوية + بيانات البنك

6

سجّل في Mailgun

mailgun.com → أضف domain: mg.yassiru.com → أضف DNS records المطلوبة

7

Google Analytics

analytics.google.com → Property جديد → Web Stream → انسخ ID: G-XXXXXXXXXX

8

Google Search Console

search.google.com/search-console → أضف yassiru.com → تحقق بـ DNS → أرسل Sitemap

يوم 3-4

🖥️ إعداد السيرفر والنشر الأول

1. الاتصال وتثبيت Docker

# اتصل بالسيرفر
ssh root@[IP_ADDRESS]

# حدّث النظام
apt update && apt upgrade -y

# ثبّت Docker + Git
curl -fsSL https://get.docker.com | sh
apt install docker-compose-plugin git -y

2. رفع المشروع

# لو عندك GitHub
cd /opt
git clone https://github.com/USER/yassiru.git
cd yassiru

# لو مفيش GitHub — ارفع من جهازك
scp -r ./yassiru root@[IP]:/opt/

3. ملف البيئة

cp .env.production.example .env.production
nano .env.production
APP_KEY=[ولّده من جهازك]
APP_URL=https://yassiru.com
DB_PASSWORD=[كلمة مرور قوية]
FAWRY_MERCHANT_CODE=[من فوري]
FAWRY_SECURITY_KEY=[من فوري]
MAIL_USERNAME=[من Mailgun]
MAIL_PASSWORD=[من Mailgun]
GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX

4. التشغيل

# شغّل كل الحاويات
docker compose -f docker-compose.prod.yml up -d

# شغّل الترحيلات والبيانات
docker exec yassiru-app php artisan migrate --force
docker exec yassiru-app php artisan db:seed

# فعّل الكاش
docker exec yassiru-app php artisan config:cache
docker exec yassiru-app php artisan route:cache

# فعّل SSL
bash scripts/init-ssl.sh
docker restart yassiru-nginx
