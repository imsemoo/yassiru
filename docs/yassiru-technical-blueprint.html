04 — الـ API

API Endpoints

🔐 Auth

POST/api/auth/register
تسجيل مستخدم جديد (اسم، إيميل، رقم، كلمة مرور، جنس، مدينة)
POST/api/auth/login
POST/api/auth/verify-identity
رفع صورة الهوية للتحقق (إلزامي للمعرّفين)

🎓 Courses

GET/api/courses
قائمة الكورسات المتاحة حسب المسار
GET/api/courses/{id}/lessons
دروس كورس محدد
POST/api/courses/{id}/progress
تحديث تقدم المستخدم في درس
POST/api/quizzes/{id}/attempt
تقديم إجابات الاختبار
GET/api/certificates/mine
شهاداتي

🤝 Matching

POST/api/recommender/register
تسجيل كمُعرِّف موثوق (نوع، مؤسسة، ميثاق شرف)
POST/api/recommender/candidates
تسجيل مرشح جديد (بيانات + بيانات ولي الأمر)
GET/api/recommender/candidates
المرشحون المسجلون عند هذا المُعرِّف
GET/api/recommender/suggestions
اقتراحات توافق من النظام للمعرّف
POST/api/recommender/recommend
إنشاء توصية (ربط مرشح بمرشحة)
PUT/api/family-requests/{id}/respond
رد العائلة على التوصية (قبول/رفض)

💰 Fund

POST/api/circles
إنشاء حلقة تيسير جديدة
GET/api/circles?city={id}
الحلقات المتاحة في مدينة
POST/api/circles/{id}/join
الانضمام لحلقة
POST/api/circles/{id}/contribute
دفع المساهمة الشهرية
GET/api/circles/{id}/dashboard
لوحة الحلقة: من دفع، الجدول، الإحصائيات

💒 Wedding + 🧮 Calculator

GET/api/weddings?city={id}
الأعراس الجماعية القادمة في مدينة
POST/api/weddings/{id}/register
التسجيل في عرس جماعي
GET/api/vendors?city={id}&category={cat}
مقدمو خدمات بخصومات
POST/api/calculator
حاسبة تكاليف الزواج (مدينة + متطلبات)

07 — منطق الصندوق

خوارزمية صندوق التيسير

app/Services/FundCalculationService.php — المنطق الأساسي
// حلقة من 15 عضو × 1000 جنيه/شهر
// ═══════════════════════════════════
// الشهر 1: كل الأعضاء يدفعون 1000 → عضو #1 يستلم 15,000
// الشهر 2: كل الأعضاء يدفعون 1000 → عضو #2 يستلم 15,000
// ...حتى الشهر 15: عضو #15 يستلم 15,000
// ═══════════════════════════════════

// ترتيب الاستلام:
// 1. بالقرعة العشوائية (lottery) — الأعدل
// 2. بالأولوية (priority) — الأكثر حاجة أولاً (تصويت المجموعة)
// 3. بالجدول (schedule) — ترتيب الانضمام

// حماية من التخلف عن الدفع:
// - إشعار تذكير قبل 3 أيام من موعد الدفع
// - مهلة 5 أيام بعد الموعد
// - بعد المهلة: تنبيه لكل الأعضاء + تجميد العضوية
// - بعد 15 يوم: حذف من الحلقة + إبلاغ الإدارة
// - ضمان: كل عضو يوقع عقد التزام رقمي عند الانضمام
08 — الأمان

Security & Privacy

🔒 أمان البيانات

• HTTPS everywhere (Let's Encrypt)
• بيانات حساسة مشفرة (AES-256)
• Laravel Sanctum + CSRF Protection
• Rate Limiting على كل Endpoints
• Input Validation + SQL Injection Prevention
• XSS Protection مفعّل
• Cloudflare WAF + DDoS Protection

🛡️ خصوصية المستخدم

• لا صور تُخزّن على السيرفر
• بيانات المرشحين مرئية فقط لمعرّفهم
