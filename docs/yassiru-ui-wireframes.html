ملاحظات التصميم

قواعد هامة للتنفيذ

📱 الموبايل

• 70%+ من المستخدمين على الموبايل — Mobile First
• Bootstrap Grid System يتكفل بالـ Responsive
• Navbar يتحول لـ Hamburger Menu
• الجداول تتحول لبطاقات على الشاشات الصغيرة
• أزرار بحجم مناسب للإصبع (min-height: 44px)

🎨 قواعد التصميم

• لا إسراف في الزخارف — تصميم نظيف ومحترم
• خط Amiri حصرياً للآيات والأحاديث
• خط Cairo لكل شيء آخر
• ألوان دافئة (Warm Palette) — لا ألوان صارخة
• Border-radius: 16px للبطاقات الكبيرة، 8px للأزرار
• المسافات كبيرة — المحتوى يتنفس
